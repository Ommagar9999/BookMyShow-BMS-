# 🎬 BookMyShow Clone (BMS)

A Full Stack Movie Ticket Booking Application inspired by BookMyShow.

## 🚀 Features

* User Registration & Login
* Movie Search & Browsing
* Multi-City Theater Management
* Multi-Screen Support
* Show Scheduling
* Dynamic Seat Selection
* Real-Time Seat Availability
* Ticket Booking & Cancellation
* Booking History
* Admin Dashboard
* Responsive UI using Bootstrap 5

## 🛠 Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* Maven

### Frontend

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

### Database

* MySQL
